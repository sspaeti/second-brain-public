# Popover V2 (Full-Content Hover Previews) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Quartz-v4-style hover popover that fetches the full rendered note (scrollable, with anchor scrolling and image/PDF previews), gated behind a new config flag `enableLinkPreviewV2`, while keeping the existing v1 popover intact as the default.

**Architecture:** Mirror Quartz v4 (`/home/sspaeti/git/sspaeti.com/quartz_v4/quartz/components/scripts/popover.inline.ts`): on `mouseenter` over an `.internal-link`, `fetch(link.href)`, branch on `Content-Type`, and either (a) parse HTML and extract `.popover-hint` elements into a `position: fixed` overlay on `<body>`, (b) render an `<img>` for image responses, or (c) embed an `<iframe>` for PDFs. Cache per pathname. Scroll to `#heading` anchors via prefixed IDs. Selection of v1 vs v2 happens in `layouts/partials/head.html` via the new config flag. Separately, fix non-`!` image wikilinks (`[[img.webp]]`) so they emit a working `<a href>` and the rust util copies the asset — that makes image previews work end-to-end.

**Tech Stack:** Hugo templates (Go), vanilla JS (no bundler), SCSS, Rust (obsidian-quartz CLI util), FloatingUI (already loaded globally as `window.FloatingUIDOM`).

**Note on testing:** This project has no automated JS/template test suite. Verification is done via `make serve` (Hugo dev server on `http://localhost:1313/brain/`), browser hover checks, and `curl` against the dev server for asset/header checks. Each task lists the precise manual verification command and expected outcome.

## Task 3: Create v2 popover JavaScript

**Files:**
- Create: `assets/js/popover-v2.js`

- [ ] **Step 1: Write the v2 popover script**

Create `assets/js/popover-v2.js`:

```javascript
// Popover v2: full-content fetch-based previews (Quartz v4 style).
// Triggered by initPopoverV2(baseURL) when the enableLinkPreviewV2 flag is true.
// Internal links rendered with class="internal-link" and href.
// Branches on Content-Type: text/html -> extract .popover-hint elements;
// image/* -> render <img>; application/pdf -> embed <iframe>.

(function () {
  const popoverCache = new Map(); // pathname -> Promise<HTMLElement|null>
  let activeAnchor = null;

  function clearActivePopover() {
    activeAnchor = null;
    document.querySelectorAll(".popover-v2").forEach((el) => {
      el.classList.remove("active-popover");
    });
  }

  function setPosition(link, popoverElement, clientX, clientY) {
    const FUI = window.FloatingUIDOM;
    if (!FUI) return;
    FUI.computePosition(link, popoverElement, {
      strategy: "fixed",
      middleware: [FUI.inline({ x: clientX, y: clientY }), FUI.shift(), FUI.flip()],
    }).then(({ x, y }) => {
      Object.assign(popoverElement.style, {
        transform: `translate(${Math.round(x)}px, ${Math.round(y)}px)`,
      });
    });
  }

  function buildHtmlPopover(html, targetUrl) {
    // Prefix every id with "popover-internal-" so duplicates do not collide
    // with the host page's IDs.
    html.querySelectorAll("[id]").forEach((el) => {
      el.id = "popover-internal-" + el.id;
    });
    // Rewrite relative URLs so links/images inside the popover still resolve.
    html.querySelectorAll("[href], [src]").forEach((el) => {
      const attr = el.hasAttribute("href") ? "href" : "src";
      const val = el.getAttribute(attr);
      if (!val) return;
      // Skip anchors and absolute URLs.
      if (val.startsWith("#") || /^[a-z]+:\/\//i.test(val) || val.startsWith("//")) return;
      try {
        el.setAttribute(attr, new URL(val, targetUrl).toString());
      } catch (_) {
        // ignore malformed URLs
      }
    });

    const hints = [...html.getElementsByClassName("popover-hint")];
    if (hints.length === 0) return null;

    const inner = document.createElement("div");
    inner.classList.add("popover-v2-inner");
    inner.dataset.contentType = "text/html";
    hints.forEach((h) => inner.appendChild(h));
    return inner;
  }

  function buildImagePopover(url) {
    const inner = document.createElement("div");
    inner.classList.add("popover-v2-inner");
    inner.dataset.contentType = "image/*";
    const img = document.createElement("img");
    img.src = url;
    img.alt = "";
    inner.appendChild(img);
    return inner;
  }

  function buildPdfPopover(url) {
    const inner = document.createElement("div");
    inner.classList.add("popover-v2-inner");
    inner.dataset.contentType = "application/pdf";
    const iframe = document.createElement("iframe");
    iframe.src = url;
    inner.appendChild(iframe);
    return inner;
  }

  async function fetchAndBuild(targetUrl) {
    let response;
    try {
      response = await fetch(targetUrl.toString(), { credentials: "same-origin" });
    } catch (e) {
      console.warn("[popover-v2] fetch failed", e);
      return null;
    }
    if (!response.ok) return null;

    const contentTypeHeader = response.headers.get("Content-Type") || "";
    const [contentType] = contentTypeHeader.split(";");
    const [category, subtype] = contentType.trim().split("/");

    let inner = null;
    if (category === "image") {
      inner = buildImagePopover(targetUrl.toString());
    } else if (category === "application" && subtype === "pdf") {
      inner = buildPdfPopover(targetUrl.toString());
    } else {
      const text = await response.text();
      const parsed = new DOMParser().parseFromString(text, "text/html");
      inner = buildHtmlPopover(parsed, targetUrl);
    }
    if (!inner) return null;

    const outer = document.createElement("div");
    outer.classList.add("popover-v2");
    outer.appendChild(inner);
    document.body.appendChild(outer);
    return outer;
  }

  function getCacheKey(link) {
    return link.pathname + link.search;
  }

  async function onMouseEnter(event) {
    const link = event.currentTarget;
    if (!link.href) return;
    if (link.dataset.noPopover === "true") return;

    activeAnchor = link;

    const targetUrl = new URL(link.href);
    const hash = decodeURIComponent(targetUrl.hash || "");
    targetUrl.hash = "";

    const key = getCacheKey(targetUrl);
    if (!popoverCache.has(key)) {
      popoverCache.set(key, fetchAndBuild(targetUrl));
    }

    const popoverElement = await popoverCache.get(key);
    if (!popoverElement) return;
    if (activeAnchor !== link) return; // user moved on

    clearActivePopover();
    popoverElement.classList.add("active-popover");
    setPosition(link, popoverElement, event.clientX, event.clientY);

    // Scroll to a heading if the link had a hash.
    if (hash) {
      const inner = popoverElement.querySelector(".popover-v2-inner");
      const target = inner && inner.querySelector("#popover-internal-" + CSS.escape(hash.slice(1)));
      if (target && inner) {
        inner.scroll({ top: target.offsetTop - 12, behavior: "instant" });
      }
    }
  }

  function onMouseLeave() {
    clearActivePopover();
  }

  window.initPopoverV2 = function initPopoverV2() {
    const links = document.querySelectorAll("a.internal-link[href]");
    links.forEach((link) => {
      link.addEventListener("mouseenter", onMouseEnter);
      link.addEventListener("mouseleave", onMouseLeave);
    });
  };
})();
```

## Task 5: Mark popover-hint elements + add reading time

The v2 script extracts **only** elements with class `popover-hint` from the fetched page. Everything else is naturally excluded. The popover will contain exactly: title (`h1.p-name`), meta line (last updated + created + reading time), and content body (`div.e-content`).

**Excluded by design (opt-in selector — DO NOT mark these):**
- `partial "header.html"` (site header / nav bar)
- `partial "toc.html"` (table of contents)
- `<ul class="tags">` (tags list)
- `partial "footer.html"` (which embeds `partial "graph.html"` — interactive graph)
- `<div class="backlinks-container">`
- `<div id="webmentions">`

If a future change adds `popover-hint` to any of those, popovers will start including them — that is the only failure mode here.

Reading time does not currently exist on rendered pages. We add it to the meta line using Hugo's built-in `.ReadingTime` so it appears on the page and (because the meta line is `popover-hint`) inside the popover.

## Out of scope (intentionally deferred)

These were considered and deliberately left for a follow-up plan:

1. **Shrinking `contentIndex.json`.** Removing the `content` field would break full-text search (`assets/js/full-text-search.js:24-27` indexes it). The `description` field in frontmatter is not a substitute — search relies on body content for matches. Not worth doing as part of this feature.

2. **Lazy-loading `contentIndex.json` until cmd+k.** With v2 ON, the popover no longer reads the content index, so the index could in principle be fetched on-demand when the search modal opens. This is a real page-speed win (~2.4 MB skipped on first paint) but touches `head.html`, `full-text-search.js`, and `backlinks.html` cohesively. File it as a follow-up.

3. **PDF popovers.** `popover-v2.js` already handles `application/pdf` responses, but this codebase has no `[[somefile.pdf]]` use case identified. Works automatically if such links exist; no special wikilink handling added.

4. **Removing the v1 popover code path.** Kept intentionally per the user's request (the flag must keep both available).
